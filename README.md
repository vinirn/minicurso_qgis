# Minicurso de QGIS

Página de recursos para os participantes do minicurso **Introdução ao QGIS com aplicações em dados ambientais, infraestrutura e energia renovável**.

O arquivo [`index.html`](index.html) reúne os links para os dados usados nas atividades. O primeiro recurso é a página de malhas territoriais do IBGE, indicada para obter as malhas do Rio Grande do Norte.
