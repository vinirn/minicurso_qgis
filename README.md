# Minicurso de QGIS

Página de recursos para os participantes do minicurso **Introdução ao QGIS com aplicações em dados ambientais, infraestrutura e energia renovável**.

O arquivo [`index.html`](index.html) reúne os links para os dados usados nas atividades: as malhas territoriais e as áreas urbanizadas do IBGE, o OpenStreetMap, as bases do BIT, da ANEEL, da EPE, da ANA, do SIGMINE (ANM), do CAR (Cadastro Ambiental Rural), do MapBiomas e do Brazil Data Cube (INPE), e o GeoPackage [`RN_massas_dagua.gpkg`](dados/RN_massas_dagua.gpkg) disponibilizado neste repositório.

Os símbolos para usar no QGIS estão na pasta [`svg`](svg): dois ícones de aerogerador e quatro ícones de energia solar. A página de recursos mostra uma prévia de cada arquivo e oferece links para baixar os SVGs.

Para interpretar e simbolizar o GeoTIFF de cobertura da terra, a página de recursos também aponta para a tabela oficial de códigos, classes e cores e para o pacote de legenda para QGIS da Coleção 11 do MapBiomas.
