# Minicurso de QGIS

Página de recursos para os participantes do minicurso **Introdução ao QGIS com aplicações em dados ambientais, infraestrutura e energia renovável**.

O arquivo [`index.html`](index.html) reúne os links para os dados usados nas atividades: as malhas territoriais do IBGE, o OpenStreetMap, as bases do BIT e da ANA, e o GeoPackage [`RN_massas_dagua.gpkg`](dados/RN_massas_dagua.gpkg) disponibilizado neste repositório.
